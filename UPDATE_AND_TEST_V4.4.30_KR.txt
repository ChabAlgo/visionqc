VisionQC v4.4.30 대상 PC 검증 순서
==================================

1. 버전
- Web 제목/VERSION: 4.4.30
- Agent /api/status agentVersion: 0.2.8
- 설치 VPDL이 4.2이면 vpdlVersion: 4.2

2. Keyword Mode
- Keyword 모드 OFF: Keyword Input Root 입력과 선택 버튼이 disabled
- Keyword 모드 ON: Keyword Input Root 입력과 선택 버튼이 enabled
- ON일 때 Position별 Image Folder는 공통 루트 방식에 맞게 잠김

3. 파일/폴더 Picker
- Keyword Input Root 선택을 열고 취소한 뒤 즉시 다시 열기
- Workspace, Image Folder, Output, CSV, Fallback Sample Image를 차례로 열고 취소/선택
- '다른 선택 창이 이미 열림'이 남으면 같은 탭의 이전 창이 자동 닫히고 새 창이 열리는지 확인
- 다른 브라우저 탭에서 연 정상 선택창은 강제로 닫히지 않아야 함

4. Agent 종료/연결 끊김
- Runtime File Load 완료 후 Agent 종료
- Runtime token, READ OK, Stream/Tool 카드가 화면에서 사라지는지 확인
- Workspace 경로 입력은 그대로 남는지 확인
- Agent 재실행 후 Runtime File Load를 다시 요구하는지 확인

5. Tool/Progress
- Progress Update를 3으로 변경
- Tool 두 개 선택 후 '선택 제거'
- 선택 Tool만 사라지고 Progress Update/JPEG/GPU/HeatMap 값이 유지되는지 확인
- Tool 추가 후 다른 파라미터가 기본값으로 초기화되지 않는지 확인

6. Runtime preload/Simulation
- Workspace Runtime Structure 안의 Runtime File Load 실행
- 완료 token이 생긴 뒤 Simulation Start
- Start 직후 Workspace를 다시 로드하지 않고 사전 로드 Runtime 연결로 시작하는지 확인
- Agent 로그의 PROGRESS/INFO가 같은 batch에서 중복되지 않는지 확인

7. FHD UI
- 1920x1080, 브라우저 100% 배율
- 메뉴 확장 시 본문이 가려지지 않는지 확인
- Simulation Options 외부 클릭 후 scrollTop 유지
- Tool Settings/Fallback/Preview에 가로 scrollbar가 생기지 않는지 확인
- 텍스트 드래그 후 마우스를 놓아도 선택이 유지되는지 확인
