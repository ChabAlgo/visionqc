VisionQC GitHub 업데이트 체크리스트
===================================

[새 버전 배포]
1. 새 VisionQC 버전을 먼저 로컬에서 테스트한다.
2. GitHub Desktop에서 visionqc 저장소를 연다.
3. Fetch origin을 누른다.
4. 새 GitHub Pages 배포본의 파일을 저장소 폴더에 덮어쓴다.
   - .git 폴더는 절대 삭제하지 않는다.
5. GitHub Desktop의 Changes에서 변경 파일을 확인한다.
6. Summary 예: Release VisionQC v4.4.11
7. Commit to main
8. Push origin
9. 웹사이트 정상 동작 확인
10. 정상이라면 해당 Commit에 Tag v4.4.11 생성
11. GitHub에서 Release v4.4.11 생성
12. Offline ZIP이 있으면 Release asset으로 첨부

[문제가 생겼을 때]
1. GitHub Desktop → History
2. 문제를 만든 Commit 우클릭
3. Revert Changes in Commit
4. Push origin
5. 웹사이트가 이전 안정 상태로 돌아왔는지 확인

운영 main에 이미 Push한 기록은 Reset/Delete보다 Revert를 우선 사용한다.
