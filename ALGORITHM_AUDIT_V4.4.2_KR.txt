VisionQC 계산/알고리즘 검증 기록

1. Cell NG율 = Threshold 적용 후 한 Position 이상 NG인 고유 Cell 수 / 전체 고유 Cell 수
2. Position NG율 = 해당 Position 최종 NG 건수 / 해당 Position 검사 건수
3. Tool 구성 비율 = 해당 Position 최종 NG 건수 중 해당 Tool도 NG인 건수 / 해당 Position 최종 NG 건수
   - 동일 Cell에서 복수 Tool이 NG일 수 있으므로 합계 100% 초과 가능
4. Threshold 처리 = 원본 Tool_result가 NG일 때 NG Score 중 하나라도 Threshold 이상이면 NG 유지, 모두 미만이면 OK
   - 원본 OK는 NG로 역전하지 않음(Score가 선택 결과 confidence라는 입력 정의에 따름)
5. Position 최종 결과 = Tool 중 하나라도 NG면 NG, 모두 OK면 OK
6. Cell 최종 결과 = 입력된 Position 중 하나라도 NG면 NG
7. 미검 = 동일 Cell ID + Position이 결과 CSV와 NG Image 폴더 양쪽에 존재하고, Threshold 적용 Position 최종 결과가 OK
8. 실제 NG 수 = NG Image 폴더의 고유 Cell ID + Position 수
9. CSV 매칭 = 실제 NG 중 결과 CSV에 같은 Cell ID + Position이 있는 수
10. 미매칭 = 실제 NG 중 결과 CSV에 같은 Cell ID + Position이 없는 수
11. 정상 검출 + 미검 = CSV 매칭 수
12. 중복 결과 행은 Cell ID + Position으로 집계하며 하나라도 NG면 NG, Threshold는 NG 행 Score 중 하나라도 기준 이상이면 NG 유지
