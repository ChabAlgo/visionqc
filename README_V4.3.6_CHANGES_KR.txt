VisionQC Web v4.3.6 변경 사항

1. 메인/분석/설정 화면 클릭 불가 수정
- 확장 화면을 기존 분류 화면보다 높은 독립 레이어로 변경
- 분류 화면 main이 투명하게 클릭을 가로채지 않도록 비분류 화면에서 pointer-events와 visibility 차단
- 버튼, 탭, 설정 입력 및 분석 드롭다운이 실제 클릭을 받도록 수정

2. 메뉴 버튼 강제 입력 처리
- 브라우저/React 레이어와 무관하게 window pointerdown 캡처 단계에서 메뉴 버튼 좌표를 판정
- 메뉴와 내비게이션 항목을 직접 전환하도록 보강

3. 분석 필터 순서 변경
- Position → Tool → 분석 범위 순서

4. 상단 헤더 재배치
- 브랜드, Progress, 라벨 통계 사이 빈 공간 제거
- 라벨 통계 영역을 유동 폭으로 확대
- 우측 기능 버튼을 우측 밀착 및 최대 2줄 배치
- 한 화면에 더 많은 라벨별 개수가 보이도록 조정

5. 가독성
- 분석 화면 제목, 안내, 필터, 버튼 글자 크기 추가 확대
