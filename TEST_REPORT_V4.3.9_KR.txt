VisionQC Web v4.3.9 검증 기록

검증 환경
- Chromium headless + Playwright
- VisionQC React 헤더 구조를 모사한 DOM에 실제 visionqc-extension.js/CSS를 로드

확인 항목
1. 분석 범위 드롭다운
   - 선택 Tool의 OK Score
   - 선택 Tool의 NG Score
   - 미검 Cell의 OK Score
   - 항목 선택 후 화면 재렌더링 확인

2. 전체 결과 CSV
   - 다운로드 이벤트 발생 확인
   - 하나의 CSV에 Cell ID, Position, Total_result, Tool별 result/score 생성 확인
   - 테스트 데이터 3건 내용 직접 파싱 확인

3. Score 조건 CSV
   - Score 입력값 0.60, 조건 이상(>=) 적용
   - 현재 Position/Tool/분석 범위 결과 중 조건 충족 데이터만 CSV 생성 확인
   - Cell ID, Position, Tool, Result, Score, Condition, Source 정보 확인

4. Threshold 시뮬레이션
   - Position+Tool별 Threshold 입력 박스 생성 확인
   - Crack Threshold를 0.50 -> 0.95로 변경
   - Position NG율 50.00% -> 0.00%로 실시간 재계산 확인
   - Tool별 원본 NG 최소 Score 표시 확인

5. 정적 파일
   - visionqc-extension.js node --check 통과
   - root/dist extension JS 및 CSS 동기화
   - HTML 캐시 버전 v4.3.9 적용

Threshold 연산 규칙
- CSV에서 원래 Tool_result=NG인 결과 중 Tool_score >= Threshold인 결과만 NG로 유지
- 원래 Tool_result=OK인 결과는 Threshold로 NG로 뒤집지 않음
- Tool Threshold 적용 후 어느 Tool이라도 NG이면 Position NG
- 어느 Position이라도 NG이면 Cell NG
