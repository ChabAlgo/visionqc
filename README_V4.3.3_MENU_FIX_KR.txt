VisionQC DirectExport v4.3.3 메뉴 수정

수정 내용
- 메뉴 버튼 클릭 이벤트를 매 초기화 시 확실하게 재연결
- 이전 버전 DOM이 남아 있어도 현재 이벤트가 정상 동작하도록 보강
- 메뉴 버튼/배경/서랍의 z-index를 최상위로 조정
- CSS class 외 직접 스타일 보조 적용
- extension CSS/JS에 v4.3.3 캐시 무효화 쿼리 적용

실행 전 중요
1. 실행 중인 기존 VisionQC 검은 CMD 창을 모두 닫습니다.
2. 기존 브라우저 탭도 닫습니다.
3. 이 폴더의 run_app.bat을 실행합니다.
4. 화면 버전이 v4.3.3인지 확인합니다.
