VisionQC v4.4.23 Simulation 사용 전

권장 Local Agent: v0.2.3

[업데이트]
1. v0.2.3 Source 압축 해제
2. BUILD_RELEASE_x64.cmd
3. 반드시 오류 0개 확인
4. REGISTER_PROTOCOL.cmd 실행
   - 실행 중인 구버전 Agent를 먼저 종료
   - 현재 v0.2.3 EXE 경로로 visionqc-agent:// 등록 덮어쓰기
   - 마지막 reg query 출력에서 경로 확인
5. CHECK_PROTOCOL.cmd
   - Registry 경로와 현재 실행 중 Agent version 확인
6. RUN_AGENT.cmd 또는 Web -> Agent 실행
7. Chrome: http://127.0.0.1:17891/api/status
   - agentVersion = 0.2.3 확인
8. VisionQC -> 시뮬레이션 -> 연결 확인

[구버전 0.1.2가 계속 실행되는 이유]
visionqc-agent:// URL protocol은 REGISTER_PROTOCOL.cmd를 실행했던 당시의 EXE 절대경로를 Windows Registry에 저장합니다.
따라서 v0.2.3을 새 폴더에 풀고 BUILD만 한 경우 Web의 Agent 실행 버튼은 여전히 예전 0.1.2 EXE를 실행할 수 있습니다.
또 이미 0.1.2가 127.0.0.1:17891을 사용 중이면 Web의 상태 확인도 0.1.2를 보게 됩니다.
새 v0.2.3의 REGISTER_PROTOCOL.cmd를 다시 실행하면 두 문제를 함께 정리하도록 구성했습니다.
