VisionQC v4.4.30 + Local Agent v0.2.8 시작 안내
================================================

Web 배포
1. GitHubPages ZIP의 내용을 repository root에 덮어씁니다.
2. index.html이 assets/index-v4.4.30.js와 visionqc-v4430-clean.css를 참조하는지 확인합니다.
3. GitHub Pages 배포 완료 후 강력 새로고침(Ctrl+Shift+R)합니다.

Agent 갱신
1. 실행 중인 구버전 Agent를 먼저 종료합니다.
2. LocalAgent v0.2.8 폴더에서 BUILD_RELEASE_x64.cmd를 실행합니다.
3. VPDL이 기본 경로가 아니면 다음 중 하나를 사용합니다.
   BUILD_RELEASE_x64.cmd "D:\Cognex\Cognex Deep Learning Studio"
   또는 COGNEX_VPDL_DLL_DIR 환경변수 지정
4. 빌드 오류 0개를 확인합니다.
5. 새 폴더의 REGISTER_PROTOCOL.cmd를 반드시 실행합니다.
6. CHECK_PROTOCOL.cmd와 /api/status에서 agentVersion 0.2.8을 확인합니다.

중요
- Web v4.4.30과 Agent v0.2.8을 함께 사용하세요.
- 이전 Agent가 계속 실행 중이면 새 선택창 복구 API가 없어 BUSY 문제가 유지됩니다.
- Agent 종료 시 화면의 Workspace 로드 결과는 지워지지만 사용자가 선택한 경로는 보존됩니다.
