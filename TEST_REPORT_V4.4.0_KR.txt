VisionQC Web v4.4.0 검증 기록

검증 환경
- Chromium Headless / 1600x1000 viewport
- 배포용 dist React bundle + visionqc-extension.js/CSS 실제 삽입 실행
- 테스트용 CSV/NG 이미지 모델을 브라우저 내부에 주입하여 실제 DOM 이벤트 검증

검증 항목
1. 분석 범위 드롭다운 4개 항목 표시 및 선택
   - 선택 Tool의 OK Score
   - 선택 Tool의 NG Score
   - NG Image를 NG로 검출한 Score
   - NG Image를 OK로 판정한 Score
2. 실제 NG 매칭 조건 검증
   - 동일 Cell ID + Position 이미지 존재 + Tool NG 결과만 검출 범위 포함
   - 동일 Cell ID + Position 이미지 존재 + Tool OK 결과만 OK 판정 범위 포함
3. Threshold 입력
   - AN(TOP) Crack 입력창을 마우스로 클릭
   - 키보드로 0.73 입력
   - 내부 Threshold 값 0.73 반영 확인
4. AN(TOP) 5개 Tool 레이아웃
   - 5개 Tool 카드의 Y 좌표가 동일하여 한 줄 표시 확인
5. Cell별 Score 확대 팝업
   - 확대 보기 버튼 클릭 후 팝업 열림 확인
   - 마우스 휠 입력 후 Canvas transform/Zoom 변경 확인
   - 점 Hover 시 Cell ID / Position / Result / Score Tooltip 확인
   - 점 클릭 시 매칭된 실제 NG 이미지 팝업 열림 확인
   - 이미지 팝업 X 닫기 및 Chart 팝업 X 닫기 확인
6. 정적 파일
   - visionqc-extension.js node --check 통과
   - root/dist extension JS·CSS 동기화 확인
   - server_static.mjs HTTP 200 응답 확인

참고
- 자동화 브라우저의 about:blank 테스트 컨텍스트에서는 IndexedDB 권한이 없어 복원 기능은 테스트 Seed로 대체했습니다. 실제 배포 주소(127.0.0.1:3021)의 기존 자동복원 코드는 변경하지 않았습니다.
