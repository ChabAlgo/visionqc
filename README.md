# VisionQC DirectExport v4.4.3

오프라인 정적 실행용 VisionQC 이미지 분류 및 시뮬레이션 결과 분석 프로그램입니다.

## 실행

Windows에서 `run_app.bat`을 실행합니다. Node.js는 필요하지만 `npm install`, Vite 빌드 또는 인터넷 연결은 필요하지 않습니다.

기본 주소: `http://127.0.0.1:3021/?v=4.4.3`

세부 사용법은 `README_START_HERE_KR.txt`, 이번 변경 내역은 `README_V4.4.3_CHANGES_KR.txt`를 확인하십시오.
