VisionQC v4.4.32 / Agent v0.2.10 실환경 확인

[버전 및 Runtime 상태]
1. Agent 실행 전 VPDL Runtime `-` 확인
2. Agent 실행 후 Connected, Agent 0.2.10, VPDL Runtime `미로드` 확인
3. License가 Runtime OK로 바뀌어도 VPDL Runtime은 `미로드`인지 확인
4. Runtime File Load 성공 후에만 VPDL Runtime 4.0 등 실제 버전 표시 확인

[Workspace Runtime Structure]
1. Workspace 경로만 선택한 상태에서는 Position별 LOAD WAIT 카드가 없는지 확인
2. Runtime File Load 클릭 시 로딩 카드가 나타나는지 확인
3. 성공 후 Position별 Green/Blue Stream/Tool 구조가 나타나는지 확인
4. Agent 종료 시 구조 카드가 사라지고 compact header만 남는지 확인

[파일·폴더 선택]
1. Workspace, Image Folder, Output, CSV, Keyword Root, Fallback Sample을 각각 선택/취소
2. Simulation 상단에 별도 `선택 창 취소` 버튼이 없는지 확인
3. 마지막 선택 위치를 H: 또는 네트워크 드라이브로 둔 후 Agent/Web을 다시 실행
4. 다음 선택창이 내 문서 등 로컬 위치에서 바로 나타나는지 확인
5. Windows 선택창에서 H:로 이동해 실제 파일/폴더 선택이 가능한지 확인

[회귀]
1. Keyword OFF/ON 비활성·활성
2. Tool 추가 및 선택 제거 후 다른 옵션 유지
3. Progress Update 값 유지
4. Runtime File Load 후 Simulation Start에서 Workspace 재로드 없이 시작

주의: Windows IFileDialog와 Cognex VPDL Runtime은 사용자 Windows PC에서만 최종 통합 확인할 수 있습니다.
