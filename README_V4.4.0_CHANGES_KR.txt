VisionQC Web v4.4.0 변경사항

1. Score 분석 범위를 4개로 분리
   - 선택 Tool의 OK Score
   - 선택 Tool의 NG Score
   - NG Image를 NG로 검출한 Score
   - NG Image를 OK로 판정한 Score
2. Threshold 숫자 입력창 키보드 직접 입력 가능
3. AN(TOP) 5개 Tool을 한 줄에 표시
4. Cell별 Score 확대 팝업 추가
5. 확대 팝업 휠 확대/축소, 빈 공간 드래그 이동
6. 점 Hover 시 Cell ID/Position/Score 표시
7. 점 클릭 시 매칭된 실제 NG 이미지 팝업 표시
