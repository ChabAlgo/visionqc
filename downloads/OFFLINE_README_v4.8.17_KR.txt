VisionQC Web 4.8.17 / Local Agent 1.4.17

1. VisionQC_Agent_Installer_v1.4.17.exe를 실행합니다.
2. 기존 Agent를 종료하고 프로그램을 교체하며 사용자 data/logs/output은 유지합니다.
3. 바탕화면 VisionQC 오프라인 실행 바로가기로 사용합니다.

설정 > 진단 로그·임시 기록 정리
- 자동 정리 기본값: 30일 보관 / 용량 한도 1024MB.
- 사용량 조회 후 정리 실행으로 수동 정리할 수 있습니다.
- 검사 결과 CSV, Excel, DB, 이미지와 Workspace는 정리하지 않습니다.
- 검사, Runtime 로드, 분석 중에는 정리를 미룹니다.

Position별 Tool NG 구성의 이미지 보기로 현재 날짜·Tool·Threshold 조건의 검사 이미지를 조회합니다.
방향키로 탐색하며 단일 이미지 저장은 원본 파일명을 사용합니다.
현장 H100 Runtime 로드 문제의 실제 재현 검증은 별도입니다.
