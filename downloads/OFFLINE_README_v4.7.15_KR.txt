VisionQC 오프라인 패키지 v4.7.15 / Local Agent v1.3.5

1. VisionQC_Agent_Installer_v1.3.5.exe를 실행합니다.
2. 설치가 완료되면 브라우저에서 visionqc-agent://open 또는 VisionQC의 Agent 실행 버튼으로 오프라인 화면을 엽니다.
3. VPDL Runtime과 Workspace는 설치된 PC의 Cognex 환경을 사용합니다.
4. VisionQC_Offline_v4.7.15.zip은 설치 EXE와 이 안내문을 함께 담은 오프라인 전달용 파일입니다.
5. Agent 다운로드와 오프라인 패키지 버튼은 사용자 확인 후에만 다운로드를 시작합니다.
