VisionQC 오프라인 패키지 v4.7.16 / Local Agent v1.3.6

1. VisionQC_Agent_Installer_v1.3.6.exe를 실행합니다.
2. 설치가 완료되면 브라우저에서 visionqc-agent://open 또는 VisionQC의 Agent 실행 버튼으로 오프라인 화면을 엽니다.
3. Agent는 대상 PC의 ViDi.NET.Local.dll과 bin\vidi_*.dll API 쌍을 자동 탐지합니다.
4. 정확 API Worker가 없으면 포함된 Universal Worker가 대상 PC의 VPDL DLL을 사용합니다.
5. VPDL Runtime, 라이선스 및 GPU 드라이버는 대상 PC에 정식 설치되어 있어야 합니다.
6. VisionQC_Offline_v4.7.16.zip은 설치 EXE와 이 안내문을 함께 담은 오프라인 전달용 파일입니다.
