VisionQC 4.8.2 / Agent 1.4.2

1. 포함된 설치 파일을 실행합니다. 사용자 이미지, Workspace, 저장 DB는 유지합니다.
2. 설치 후 기존 화면을 새로고침하거나 오프라인 바로가기를 실행합니다.
3. Tool별 Threshold 옆 CSV Download는 해당 Tool의 최종 NG Cell만 저장합니다.
4. 날짜별 그래프에서 Position을 체크하고 날짜 점을 선택한 뒤 CSV Download를 누르면 같은 조건의 전체 검사 Cell을 저장합니다. 전체보기는 모든 날짜가 대상입니다.
5. 검사 이력 CSV도 현재 검색 조건 전체를 저장합니다. 현재 페이지에 보이는 건수로 제한되지 않습니다.
6. 저장 폴더를 선택하면 CSV가 생성됩니다. 행 수 제한과 날짜별 분할은 Simulation Output 설정을 사용합니다.
