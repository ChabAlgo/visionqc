VisionQC 오프라인 패키지 v4.7.18 / Local Agent v1.3.8

1. VisionQC_Agent_Installer_v1.3.8.exe를 실행합니다.
2. 설치 후 바탕화면의 "VisionQC 오프라인 실행"을 실행합니다.
3. 브라우저가 열리지 않으면 http://127.0.0.1:17891/ 을 입력합니다.
4. VPDL이 없어도 분석, 검사 이력, 이미지 조회/분류, 파일 선택을 사용할 수 있습니다.
5. Runtime Load, AI 검사, Simulation에는 정상 설치된 Cognex VPDL과 라이선스/GPU 환경이 필요합니다.
6. 4.0/API 8.0과 4.2/API 8.2 전용 Worker를 포함하며, 그 외 API는 Universal 경로로 선택합니다. 모든 미래 SDK/GPU의 호환성을 보증하는 것은 아닙니다.
7. 오류가 나면 Windows 탐색기에 %LOCALAPPDATA%\VisionQC\LocalAgent\logs 를 입력해 해당 폴더를 복사해 주세요. 경로 정보가 포함되므로 외부 공유 전 확인하세요.
8. H100 PC에서 보고된 Cognex Internal Error (6cc4a157)는 현재 RTX 4050 PC에서 재현되지 않았습니다. 수정판으로 H100 PC에서 재검사 후 로그 확인이 필요합니다.
