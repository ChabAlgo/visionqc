VisionQC v4.7.0 / Local Agent v1.2.0 오프라인 패키지

1. VisionQC_Agent_Installer_v1.2.0.exe를 실행합니다.
2. 설치 EXE 하나에 Agent, SQLite 라이브러리, 오프라인 Web 자산이 포함되어 있습니다.
3. 인터넷 연결 없이 설치·Agent 실행·오프라인 웹 화면 사용이 가능합니다.
4. Cognex VPDL 검사에는 대상 PC에 Cognex VPDL Runtime/라이선스와 사용하는 Workspace가 별도로 있어야 합니다.
5. 검사 이력 DB는 %LOCALAPPDATA%\VisionQC\LocalAgent\data\visionqc-history.sqlite에 보존됩니다.
