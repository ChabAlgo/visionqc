VisionQC 4.8.1 / Agent 1.4.1

1. 포함된 설치 파일을 실행합니다. 기존 프로그램 파일은 교체하며 사용자 이미지, Workspace, 저장 DB는 유지합니다.
2. 설치 완료 후 기존 웹 화면을 새로고침하거나 바탕화면 오프라인 바로가기를 실행합니다.
3. 대용량 분석은 Agent가 연결된 상태에서 CSV 파일 여러 개를 선택합니다. Excel 호환 입력은 50MB 이하입니다.
4. Simulation Output의 CSV 행 수 기본값은 1,000,000이며 날짜별 분할을 선택할 수 있습니다.
5. 완료 결과는 Yes를 선택했을 때 영구 검사 이력에 저장합니다. No 이후 메인 상단에서 저장할 수도 있습니다.
6. Class Presets JSON 파일을 별도로 보관하면 브라우저 저장소가 초기화되어도 가져올 수 있습니다.
