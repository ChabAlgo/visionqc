VisionQC Offline 4.7.26 / Agent 1.3.16
1. ZIP을 모두 풀고 VisionQC_Agent_Installer_v1.3.16.exe를 실행하세요.
2. 바탕화면 VisionQC Offline 바로가기를 실행하세요.
3. 브라우저 주소는 http://127.0.0.1:17891/ 입니다.
4. 설정 → 분석 Input → 파일명 규칙에서 JSON 내보내기/가져오기를 사용할 수 있습니다.
5. 가져온 규칙은 형식과 값을 검증한 뒤 현재 규칙에 적용됩니다. 이름별 목록에 보관하려면 규칙 저장을 누르세요.
6. 기존 검사·판정·Workspace·CSV/SQLite 데이터는 유지됩니다.
7. VPDL이 없어도 화면과 CSV 분석 서버는 실행됩니다. 실제 GPU 검사는 VPDL·라이선스·Workspace가 필요합니다.
