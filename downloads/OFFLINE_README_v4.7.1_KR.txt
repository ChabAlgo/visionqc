VisionQC 오프라인 패키지 v4.7.1 / Local Agent v1.2.1

1. VisionQC_Agent_Installer_v1.2.1.exe를 실행합니다.
2. 설치가 끝나면 Local Agent가 등록되고 오프라인 화면이 자동으로 열립니다.
3. 오프라인 화면은 설치 EXE 안에 포함된 HTML/CSS/JS/폰트를 사용하므로 인터넷 연결 없이 실행할 수 있습니다.
4. VPDL Simulation과 AI SUGGEST Runtime 검사는 Cognex VPDL Runtime·라이선스와 설정한 Workspace가 이 PC에 있어야 합니다.
5. SQLite 이력은 %LOCALAPPDATA%\VisionQC\LocalAgent\data\visionqc-history.sqlite 에 저장됩니다. 시뮬레이션과 사용자가 저장한 CSV 결과만 새 이력으로 기록합니다.
6. 실제 NG 원본은 저장하지 않습니다. Viewer는 현재 유효한 원본 FullPath 또는 선택한 폴더 Handle에서 필요한 한 장만 읽습니다.
