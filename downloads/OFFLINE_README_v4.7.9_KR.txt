VisionQC 오프라인 패키지 v4.7.9

1. VisionQC_Agent_Installer_v1.2.3.exe를 실행합니다.
2. 설치 후 자동으로 열린 로컬 화면을 사용하거나, 바탕화면의 "VisionQC 오프라인 실행" 바로가기를 엽니다.
3. 통합 시뮬레이션은 기본적으로 Output 아래 _VisionQC_Integrated_Images에 Crop 결과를 보존하므로, 결과 CSV/분석 Viewer에서 이미지를 다시 열 수 있습니다.
4. 저장 공간을 줄이려면 Simulation Options의 "결과 Crop 이미지 유지 (Viewer용)"을 해제할 수 있지만, 해제한 실행 결과의 이미지 Viewer는 사용할 수 없습니다.

인터넷, GitHub Pages, 외부 CDN은 필요하지 않습니다.
Cognex VPDL Runtime/라이선스는 시뮬레이션 PC에 별도로 설치되어 있어야 합니다.
