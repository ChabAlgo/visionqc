VisionQC v4.4.23 정합성 점검
=============================

기준 소스
- VisionQC Web v4.4.22
- Local Agent v0.2.2
- DL_Simulation v1.13 원본 소스
- BeadGridInspector CognexRuntimeAdapter.cs

1. Simulation Options
- 전체 Simulation 재렌더 경로를 최소화했습니다.
- 일반 input/check/select: DOM 재생성 없음.
- Keyword Mode: Position list만 부분 갱신.
- Stream 변경: Tool runtime validation만 갱신.
- Tool/Judgement 구조 변경: Options panel만 교체하고 window/page/options scroll + focus 복원.
- Workspace 구조 읽기: Position list + Workspace inspector만 부분 갱신.
- 별도 마지막 CSS layer로 max-width/min-width/overflow/grid 규칙을 통일했습니다.

2. Progress Update Batch
- Agent의 analysis/progress 공용 throttle을 제거했습니다.
- 상세 결과 개수 기준으로 N개씩 analysis event를 전송합니다.
- status progress도 동일한 N 경계에서 전송합니다.
- 동일 processed count 중복 event는 제거합니다.
- Batch=1: 1,2,3,4... / Batch=5: 5,10,15... / 완료 시 잔여값.

3. 원본 DL_Simulation 기능 대조
Green: Workspace, Image, Stream, Cell ID CSV, Keyword Mode/Input Root, GPU, GPU Device,
JPEG Quality, PrintEvery(Progress Update), KeepSubfolders, HeatMap Save, HeatMap Alpha,
Alpha Cut, ForceJet, ToolName/Threshold/Judgement, Judgement priority.
Blue: Workspace, Image, Stream, Blue Tool, GPU, GPU Device, KeepSubfolders, Save JPEG,
Skip Existing, JPEG Quality, PrintEvery, Crop W/H, Expected X Min/Max, Max Y Diff,
Fallback shift, Preview ROI, sample/preview.
Integrated: Green/Blue Workspace 공유, Blue Image Folder 공유, Cell ID CSV, Keyword,
Keep Crop, HeatMap Save 및 위 Green/Blue 상세 설정 조합.

원본 Tool Settings의 Position별 사용 체크는 사용자 요청으로 제거했습니다.
원본 Tool ROI는 원본 GUI에서도 ToolName에 따른 기본 ROI를 내부 사용하며 직접 편집 컬럼은 없으므로 그대로 유지합니다.

4. Workspace 구조 읽기
- Agent v0.2.3: 1차 DL_Simulation 엔진과 동일한 Control + path 로딩.
- 실패 시 2차 BeadGridInspector 방식 Deferred + FileStream fallback.
- Stream/Tool Children 개별 열거 실패가 전체 검사 실패가 되지 않도록 warnings 처리.
- KnownTags / KnownClasses / KnownFeatures를 reflection으로 읽습니다.

5. Tool Settings
- Position별 UI 체크박스 제거.
- ToolName dropdown 제거, text input 사용.
- Runtime 존재 상태: found=green, missing=red, structure unknown=neutral.

6. 브랜드 / 메뉴
- persistent 72px icon rail.
- top menu button click -> 252px expand/collapse.
- bottom Light/Dark, Language, Login placeholder.
- supplied TOPTEC PNG asset applied.

정적 검사
- visionqc-extension.js: node --check
- assets/index-v4.4.23.js: node --check
- index.html local asset references existence check
- data-vq-action -> runAction handler coverage check
- ZIP integrity check 예정/패키징 시 수행

제한
이 실행환경에는 Windows .NET Framework + Cognex VPDL 4.0 Runtime이 없어 Agent EXE 실제 빌드 및 VPDL Workspace/GPU E2E 테스트는 할 수 없습니다.
Chromium은 조직 정책으로 local/file test navigation이 제한되어 실제 클릭/레이아웃 E2E도 완료하지 못했습니다.
따라서 Agent는 VPDL PC에서 BUILD_RELEASE_x64.cmd로 최종 컴파일 확인이 필요합니다.
