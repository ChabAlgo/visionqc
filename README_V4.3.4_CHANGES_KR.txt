VisionQC DirectExport v4.3.4 변경 사항

1. 메뉴 열림 구조를 JavaScript 클릭 이벤트에서 브라우저 기본 checkbox/label 방식으로 교체했습니다.
   - 다른 UI 레이어가 클릭 이벤트를 가로채도 메뉴가 열립니다.
   - 메뉴 배경 또는 닫기 버튼을 누르면 닫힙니다.
2. 상단 기능 버튼 영역을 오른쪽 정렬했습니다.
3. Label Reset 버튼을 추가했습니다.
   - 실행 전 확인 창이 표시됩니다.
   - 확인 시 현재 불러온 모든 이미지의 라벨만 초기화합니다.
   - 이미지 목록과 현재 위치는 유지되며 자동 저장에 반영됩니다.
