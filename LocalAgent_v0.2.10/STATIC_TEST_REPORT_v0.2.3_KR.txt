VisionQC Local Agent v0.2.3 Build Hotfix 정적 검증
====================================================

수정 원인
- 제공된 Windows MSBuild 로그: AgentServer.cs(237,62) CS1503 int -> ulong
- 제공된 Windows CMD 로그: UTF-8 BOM이 `癤?echo off`로 실행됨

수정 내용
- GPU 장치 인덱스를 OptimizedGPUMemory(ulong)에 전달하던 호출 제거
- GPU 장치 선택은 InitializeComputeDevices(mode, gpuList)에 유지
- GPU 최적화 메모리는 설치된 VPDL Runtime 기본 설정 유지
- CMD 9개 파일에서 UTF-8 BOM 제거

자동 정적 회귀 검사: 6/6 PASS
- InitializeComputeDevices 호출 유지 / 잘못된 OptimizedGPUMemory(gpuList) 호출 없음
- 모든 CMD에 UTF-8 BOM 없음
- 모든 CMD 첫 줄이 @echo off
- 모든 CMD가 ASCII-safe
- csproj의 C# Compile Include 파일이 모두 존재
- Agent/Assembly 버전 0.2.3 정합성
- .NET Framework 4.8 / x64 / C# 7.3 프로젝트 설정 유지

원본 대조

- 9개 CMD의 실행 내용 변경은 없고 BOM 3byte만 제거
