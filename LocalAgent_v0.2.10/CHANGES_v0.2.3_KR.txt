VisionQC Local Agent v0.2.3
============================

0. Build hotfix
- Workspace Inspect fallback의 `OptimizedGPUMemory(gpuList[0])` 제거
- 해당 API는 GPU 인덱스가 아니라 예약 메모리 byte 수(`ulong`)를 받으므로 장치 선택은 `InitializeComputeDevices`만 사용
- 모든 CMD 스크립트의 UTF-8 BOM 제거 (`癤?echo off` 오류 방지)

1. Progress Update exact batching
- Batch=1: 1,2,3,4... 매 이미지 경계
- Batch=5: 5,10,15... 경계
- 완료/중지 시 남은 마지막 Batch flush
- Green/Integrated의 LiveRecord + Processed 중복 event는 같은 processed count 한 번만 Status 전송
- analysis와 progress throttle 완전 분리

2. Detailed logging / ETA
- START / INFO / WARN / PROGRESS / DONE / STOP / ERROR SSE log
- PROGRESS 로그: Processed/Total, %, OK/NG, img/s, ETA
- SimulationState: elapsedSeconds / etaSeconds / imagesPerSecond / batchSize

3. Workspace Inspect 안정화
- 1차: DL_Simulation v1.13 엔진과 동일한 LocalRuntime.Control + Workspaces.Add(name,path)
- 2차 fallback: BeadGridInspector의 Deferred + FileStream
- 1차 실패/2차 성공 시 warning에 1차 원인 유지
- 두 방식 실패 시 Web에 양쪽 오류 반환
- Tool Child 열거 개별 보호
- Green KnownTags / Red KnownClasses / Blue KnownFeatures 반환

4. Tool Position 기능 제거
- AgentToolRequest의 Position별 checkbox/positionKeys 필드 제거
- Tool은 Simulation에서 활성화된 모든 Position에 동일 적용
- Custom Position 지원을 위해 Engine 내부 PositionKeys에는 활성 Position 전체를 자동 지정
