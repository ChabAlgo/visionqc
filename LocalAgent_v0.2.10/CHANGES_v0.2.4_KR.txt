VisionQC Local Agent v0.2.4
============================

1. VPDL Control 단일 소유
- Runtime Check와 Workspace Inspect가 매 요청마다 새 Control을 만들지 않고 하나를 재사용
- 두 endpoint를 단일 lock으로 직렬화해 동시 Control 생성 차단
- Simulation 시작 전 Inspect Control을 해제하고 Simulation이 끝날 때까지 새 Inspect Control 생성 차단

2. Workspace 구조 캐시
- 전체 경로 + GPU 설정을 cache key로 사용
- 파일 크기와 마지막 수정 시간이 같으면 기존 Stream/Tool/Tag/Class/Feature 결과 재사용
- 여러 Position이 같은 Workspace를 사용해도 Runtime에서 다시 열지 않음

3. Workspace fallback
- 현재 공유 Control의 EnginePath 또는 DeferredFileStream 방식을 우선 사용
- 실패할 때 기존 Control을 완전히 해제한 뒤 반대 방식으로 한 번만 재시도
- 두 Control을 동시에 만들지 않음

4. Simulation 시작 안전성
- Inspect Control 해제 후 시작 준비/Task 생성이 실패해도 VPDL 예약을 즉시 해제
- HTTP 연결을 끊는 예외 재전파 대신 명시적인 시작 실패 응답과 Agent log 반환

5. v0.2.3 build hotfix 유지
- 잘못된 OptimizedGPUMemory(GPU index) 호출 없음
- 모든 CMD UTF-8 BOM 없음
