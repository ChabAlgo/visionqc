VisionQC Local Agent v0.2.8 변경사항
====================================

1. 파일/폴더 선택창 교착 복구
- Web 브라우저 탭별 clientId를 받아 현재 선택창의 소유자를 기록합니다.
- 같은 탭에서 남은 선택창만 /api/pick/cancel로 닫을 수 있습니다.
- 다른 탭이나 다른 브라우저의 정상 선택창은 강제로 닫지 않습니다.
- IFileDialog COM 객체를 활성 구간 동안 추적하고 취소 HRESULT로 안전하게 종료합니다.

2. 선택창 가시성
- 마우스가 있는 모니터의 작업영역 중앙에 보이는 FixedDialog 소유창을 표시합니다.
- Windows 작업표시줄에서 VisionQC 선택창을 확실히 찾을 수 있습니다.

3. VPDL 설치 탐지/빌드
- VPDL 4.2 설치 경로를 4.1/4.0/5.0과 함께 탐지합니다.
- 여러 버전이 설치된 경우 빌드·상태 탐지·실행 DLL 탐색 순서를 4.2 → 4.1 → 4.0 → 5.0으로 통일합니다.
- BUILD_RELEASE_x64.cmd는 인자 또는 COGNEX_VPDL_DLL_DIR 환경변수로 SDK DLL 폴더를 받을 수 있습니다.

중요
- 컴파일 PC에는 Cognex .NET SDK 참조 DLL이 필요합니다.
- 실행 PC에서 Workspace 검사/Simulation을 하려면 호환되는 VPDL Runtime, 네이티브 종속성 및 유효한 License가 필요합니다.
- 새 폴더의 REGISTER_PROTOCOL.cmd를 실행해 브라우저 프로토콜 경로를 v0.2.8 EXE로 갱신하세요.
