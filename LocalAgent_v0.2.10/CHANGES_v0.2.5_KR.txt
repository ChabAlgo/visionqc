VisionQC Local Agent v0.2.5
============================

1. 종료 수명주기
- 5분 유휴 상태에서 자동 종료하던 IdleLoop 제거
- Web의 Agent 종료 버튼 또는 /api/agent/exit 요청 전까지 계속 실행
- 종료 버튼은 protocol 등록을 제거하지 않음

2. Runtime / License
- Agent listener 시작 직후 Runtime/License 자동 확인
- Simulation Start 직전 Web이 /api/runtime/check를 다시 호출
- status API에 cached license, runtimeMessage, instanceId 제공

3. 실시간 상태
- VPDL/GPU 장치 정보는 Agent 시작 시 한 번 읽고 status 응답에서 재사용
- Web v4.4.27이 2초 간격으로 실행/중지/재시작을 자동 감지

4. Runtime File Load
- Web의 명시적 Runtime File Load 요청을 기존 단일 VPDL Control queue/cache로 처리
- Position별 Green/Blue 결과가 완료 응답과 화면에 동일하게 반영됨

5. Fallback / Preview
- image file picker와 /api/blue/fallback/preview endpoint 유지
- Web이 slotKey 기준으로 최신 Fallback 행을 다시 찾아 선택 경로와 Preview 설정을 전달
