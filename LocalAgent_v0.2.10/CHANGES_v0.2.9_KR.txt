VisionQC Local Agent v0.2.9 변경사항

1. Picker HTTP 교착 제거
- /api/pick/start는 requestId를 등록하고 즉시 응답합니다.
- 실제 Windows Shell Dialog는 별도 STA 작업에서 실행합니다.
- /api/pick/status가 pending/complete/path/error를 반환합니다.
- Web 응답 유실 후 같은 requestId 재시도는 새 Dialog를 만들지 않습니다.

2. 선택창 취소/잔류 복구
- /api/pick/cancel은 clientId와 requestId 소유권을 모두 확인합니다.
- Dialog COM 객체가 생성되기 전 취소도 예약합니다.
- 같은 브라우저의 완료 작업은 새 선택으로 교체할 수 있고, 미수신 완료 작업은 30초 뒤 만료됩니다.

3. 느린 경로 최적화
- H: 가상 드라이브, UNC, 연결이 끊긴 네트워크 경로를 초기 폴더로 선검사하지 않습니다.
- 고정 로컬 드라이브만 빠른 초기 폴더 적용 대상으로 사용합니다.
- IFileDialog ClientGuid로 Workspace/Image/CSV/Folder별 마지막 위치를 기억합니다.

4. 오류 진단
- AgentServer 내부 예외를 소켓만 닫아 숨기지 않고 Agent ERROR 로그와 HTTP 500 JSON으로 반환합니다.
- Web v4.4.31과 함께 사용해야 새 Picker API와 구체적인 Local Network Access 진단이 적용됩니다.
