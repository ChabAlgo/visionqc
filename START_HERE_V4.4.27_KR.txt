VisionQC v4.4.27 Web + Local Agent v0.2.5
================================================

1. Local Agent 교체
- 기존 Agent를 먼저 종료합니다.
- LocalAgent_v0.2.5 폴더에서 BUILD_RELEASE_x64.cmd를 실행합니다.
- 빌드 오류 0개를 확인합니다.
- 새 폴더에서 REGISTER_PROTOCOL.cmd를 한 번 실행합니다.
- 이후에는 Web의 Agent 실행/종료만 사용하며, 종료해도 protocol 등록은 유지됩니다.

2. Web 배포
- GitHubPages_v4.4.27 폴더 내용을 repository root에 덮어씁니다.
- Commit / Push 후 GitHub Pages 배포 완료를 기다립니다.
- Chrome에서 Ctrl + Shift + R로 강력 새로고침합니다.

3. 기준 화면
- 1920 x 1080 FHD
- Chrome 배율 100%

4. 새 Simulation 순서
- Agent 실행 -> 2초 이내 Connected 및 Runtime/License 자동 표시
- Position별 Workspace/Image 경로 선택
- Output 폴더 선택
- Runtime File Load 클릭
- Position 카드 내부 Green/Blue READ OK 확인
- 필요 시 Fallback Sample Image 선택 및 미리보기
- Simulation Start

5. 중요 동작
- Workspace 선택만으로는 자동 로드하지 않습니다.
- Workspace 경로를 바꾸면 기존 READ OK는 무효화됩니다.
- Runtime File Load를 다시 완료해야 Simulation Start가 가능합니다.
- Simulation Start 직전에 License를 다시 확인합니다.
- Agent는 5분 뒤 자동 종료되지 않으며 Agent 종료 버튼 전까지 유지됩니다.

6. 실제 환경 확인
- 이 패키지의 정적/구조/ZIP 검사는 완료되었습니다.
- 실제 Cognex .vrws 로드, License, GPU, Preview는 VPDL 4.0이 설치된 Windows PC에서 확인해야 합니다.
