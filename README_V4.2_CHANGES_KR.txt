VisionQC DirectExport v4.2 변경 사항
===================================

1. 작업 자동 저장 및 새로고침 복원
- Load Folder로 불러온 작업의 이미지 목록 식별정보, 이미지별 분류값, AI 결과, 현재 이미지 위치를 브라우저 IndexedDB에 자동 저장합니다.
- F5 새로고침, 탭 종료 후 재실행, 프로그램 재실행 시 이전 작업을 복원할 수 있습니다.
- 브라우저가 폴더 접근 권한을 유지하지 않은 경우 "이전 작업 복원" 버튼을 눌러 권한을 다시 허용해야 합니다.
- 실제 이미지 파일을 브라우저에 복사하는 방식이 아니라 원본 폴더에서 다시 읽습니다. 원본 폴더를 이동/삭제하거나 파일을 교체하면 일부 항목이 복원되지 않을 수 있습니다.
- Load Files 및 Input Cell ID 방식은 브라우저 보안상 원본 파일 핸들을 재사용할 수 없으므로 새로고침 자동 복원 대상이 아닙니다. 지속 작업은 Load Folder 사용을 권장합니다.
- 자동 저장 데이터는 사용한 PC와 브라우저에 저장됩니다. 다른 PC로 자동 이전되지는 않습니다.

2. 포트 고정
- 브라우저 저장소가 매번 달라지는 문제를 막기 위해 실행 포트를 3021로 고정했습니다.
- 3021 포트가 이미 사용 중이면 기존 VisionQC CMD 창을 닫은 뒤 다시 실행하십시오.

3. 이미지 전환 단축키
- 이전 이미지: 왼쪽 방향키 또는 위쪽 방향키
- 다음 이미지: 오른쪽 방향키 또는 아래쪽 방향키
- 기존 Enter / Space 다음 이미지 기능은 유지됩니다.

4. 마우스 휠 확대/축소 개선
- 휠을 빠르게 여러 번 움직여도 첫 휠 입력 지점을 확대 중심으로 유지하도록 수정했습니다.
- 빠른 휠 입력에서 React 상태 반영이 늦어 확대 중심이 튀던 현상을 줄였습니다.
- 휠 입력량을 정규화하고 한 이벤트의 확대 단계 수를 제한했습니다.

5. 제외 사항
- VPDL Runtime, Live Camera, 카메라 SDK 기능은 이번 버전에 포함하지 않았습니다.

실행 방법
---------
run_app.bat 실행 후 브라우저에서 사용합니다.
