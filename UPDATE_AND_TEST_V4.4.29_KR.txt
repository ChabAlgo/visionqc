VisionQC v4.4.29 업데이트 및 확인

[필수 업데이트]
1. Web v4.4.29 전체 배포
2. Local Agent v0.2.7 BUILD
3. v0.2.7 REGISTER_PROTOCOL.cmd 재실행
4. 기존 Agent 종료 후 v0.2.7 실행
5. Chrome Ctrl+F5

[Tool Settings]
1. Progress Update를 3, JPEG Quality를 93으로 변경
2. Tool 추가 클릭 -> 행이 1개 늘고 두 값이 그대로인지 확인
3. Tool 2개 선택 후 선택 제거 -> 정확히 2개만 없어지는지 확인
4. 다른 GPU/HeatMap/Fallback 값도 유지되는지 확인

[Picker]
1. Workspace 선택, Image Folder 선택, Output 선택 각각 확인
2. 선택/취소 후 버튼이 즉시 원래 상태로 돌아오는지 확인
3. 선택창을 연 채 다른 선택 버튼을 눌렀을 때 두 번째 요청이 쌓이지 않는지 확인

[Runtime]
1. Runtime File Load 완료
2. Simulation Start 로그가 `사전 로드 Runtime 연결 중` 다음 즉시 Stream/Tool 확인으로 넘어가는지 확인
3. `사전 로드 Runtime을 찾지 못했습니다: ws_...`가 발생하지 않는지 확인
4. 완료 후 Runtime File Load 없이 한 번 더 Start 가능한지 확인

[Progress]
1. Progress Update=3
2. START 로그 Batch=3
3. 분석/Progress가 3, 6, 9... 단위로 갱신
4. 동일 INFO/PROGRESS가 중복되지 않는지 확인
