Agent v0.2.3 수정 사항
- AgentServer.cs(237,62): CS1503 int -> ulong
- BUILD_RELEASE_x64.cmd 첫 줄 UTF-8 BOM으로 인한 `癤?echo off`
- OptimizedGPUMemory는 GPU 번호가 아니라 메모리 byte 수를 받으므로 잘못된 호출 자체를 제거
- GPU 선택은 InitializeComputeDevices(mode, gpuList)가 담당하고 VPDL 최적화 메모리는 Runtime 기본값 유지
- BUILD/CHECK/REGISTER/RUN/STOP/TEST/UNREGISTER 등 CMD 9개의 BOM 제거

Agent 빌드/등록
1) 수정된 LocalAgent_v0.2.3 폴더에서 BUILD_RELEASE_x64.cmd 실행
2) 오류 0개와 bin\x64\Release\VisionQC.LocalAgent.exe 생성 확인
3) REGISTER_PROTOCOL.cmd 실행
4) CHECK_PROTOCOL.cmd에서 AgentVersion 0.2.3과 현재 EXE 경로 확인
5) Web에서 연결 확인 및 Workspace Runtime Structure 읽기 테스트
