VisionQC 요약 PDF 리포트

메인 화면 우측 상단의 '요약 PDF 리포트' 버튼을 누르면 별도 미리보기 창이 열립니다.
미리보기 창에서 'PDF로 저장'을 누른 뒤 브라우저 인쇄 창에서 대상을 'PDF로 저장'으로 선택하십시오.

리포트 구성
1. 검사 Cell / NG Cell / Cell NG율 / 미검 Cell-Position
2. Position별 검사 수, NG 수, NG율, 실제 NG, 정상 검출, 미검
3. Position별 Tool NG 구성, 원본 NG 최소 Score, 현재 Threshold
4. Position별 미검 요약 및 일부 Cell ID
5. 입력 결과 파일 및 실제 NG 경로

리포트는 현재 화면의 Threshold 적용 결과를 기준으로 생성됩니다.
상세 Cell/Score 자료는 기존 CSV 내보내기 기능을 사용하십시오.
