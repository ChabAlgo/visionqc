VisionQC v4.4.26 Web + Local Agent v0.2.4
================================================

1. Local Agent
- 이번 수정은 Web 요청/상태 처리 수정이므로 Agent 권장 버전은 v0.2.4로 유지합니다.
- 현재 v0.2.4가 정상 등록되어 있다면 다시 빌드/등록할 필요가 없습니다.
- 새 PC이거나 Agent가 없다면 LocalAgent_v0.2.4/BUILD_RELEASE_x64.cmd 실행 후 REGISTER_PROTOCOL.cmd를 관리자 권한으로 실행합니다.

2. Web 배포
- GitHubPages_v4.4.26 폴더 안의 파일을 repository root에 덮어씁니다.
- Commit / Push 후 GitHub Pages 배포 완료를 기다립니다.
- Chrome에서 Ctrl + Shift + R로 강력 새로고침합니다.

3. 기준 화면
- 1920 x 1080 FHD
- Chrome 배율 100%

4. 이번 버전 확인 항목
- 여러 Workspace 연속 선택 시 첫 항목은 읽는 중, 나머지는 대기 중으로 표시
- 메뉴를 이동했다 돌아와도 버튼/요약/Runtime Structure 상태가 동일
- 성공 후 READ ERROR가 남지 않고 Stream/Tool 구조가 표시
- Progress Log 시간이 17:17:26.771 [INFO] 형식
- Options가 상단 버튼과 Workspace Structure 카드를 덮지 않음
- Fallback 숫자/Sample Image 입력과 선택 버튼 높이 정렬
- Tool Settings/Fallback/Preview 가로 scrollbar 없음

5. 중요
- 첫 Workspace 로드는 Cognex Runtime과 파일 크기에 따라 시간이 걸릴 수 있습니다.
- 같은 파일의 반복 로드는 Web 10분 cache와 Agent 파일 상태 cache로 단축됩니다.
- 실제 VPDL Workspace 검증은 VPDL 4.0이 설치된 Windows PC에서 수행해야 합니다.
